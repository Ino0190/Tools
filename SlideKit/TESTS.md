# SlideKit 動作テストチェックリスト

`slide-template.html`（または `SlideKit/slide-edit.js` を載せた任意のデッキ）で確認する。
`file://` で開いてOK。複数枚で試したい時は📄で数枚に増やしてから。

## 0. 起動・基本
- [ ] ページを開くと右上にツールバー（✏️編集／📂開く／🖼画像／▦表／📍参照／📋変更をコピー／💾保存）が出る
- [ ] 各スライドの右下にページ番号（1,2,3…）が自動で付く
- [ ] 既定は閲覧モード（要素をクリックしても動かない）
- [ ] 「✏️ 編集」を押すとボタンがオレンジになり「✏️ 編集中」表示＋🎨パレットと📄ページ操作パネルが出る

## 1. 移動・リサイズ・選択
- [ ] テキストや箱をドラッグで移動できる
- [ ] 選択すると右下に丸ハンドル → ドラッグでリサイズ（右＝幅、下＝高さ、右下＝両方）
- [ ] 矢印キーで1px、Shift+矢印で10px動く
- [ ] Shift+クリックで複数選択 → まとめてドラッグ移動できる
- [ ] 複数選択の右下ハンドルで全体を同じ倍率でリサイズできる
- [ ] ⌘Z で直前の移動・リサイズが戻る（数回連続でも）
- [ ] 何もない所をクリックすると選択が解除される

## 2. 文字編集
- [ ] テキストをダブルクリックで文字を打ち替えられる
- [ ] 表のセルもダブルクリックで編集できる
- [ ] 編集して別の所をクリックすると確定する

## 3. 🎯選択中パネル（テキスト選択時）
- [ ] 文字色：hex入力／カラーピッカーで変わる（hex欄が読みやすい＝太字でない・13px）
- [ ] 背景/塗り：rect・表を選ぶと塗り色が変わる
- [ ] サイズ：－／＋で2pxずつ、数値直接入力でも変わる
- [ ] B（太字）：押すと太字ON/OFF（ONで緑に光る）
- [ ] 箇条書き「・」：先頭に・が付き、長文の折り返しが・の下に潜らず本文に揃う
- [ ] 箇条書き「①②③」：複数選択したテキストが上から①②③…で採番される
- [ ] 箇条書き「なし」：マーカーと字下げが消える

## 3.1 PowerPoint形式の箇条書き（data-bullet="native-*"）
- [ ] `<br>`で複数行入ったテキストを選んで「PowerPoint形式・」→ 1行1項目になり先頭に・が出る
- [ ] 本文をよく見るとマーカー文字は入っていない（CSSが描いている）
- [ ] テキストを選択して Tab → 全項目が1段下がる（マーカーが – に変わる）／Shift+Tab で戻る
- [ ] 上限（5段目）より深くならない・0段目より上に戻らない
- [ ] ダブルクリックで文字編集 → 行末で Enter → 同じ階層の空項目が増える
- [ ] 編集中に Tab → その行だけ階層が下がる
- [ ] 「PowerPoint形式①②③」→ ①②③で採番、Tabで下げた行は 1) 2) になる
- [ ] 上位項目を増やすと下位の採番が 1) に戻る
- [ ] 「なし」で解除すると `<br>`区切りのテキストに戻る
- [ ] ⌘Z で階層送り・方式変更が戻る
- [ ] 💾保存 → 開き直してもマーカー・階層が同じに見える
- [ ] PPTX変換 → PowerPointで開いて、項目の末尾で Enter すると次項目にマーカーが自動で付く
- [ ] PowerPointで Tab / Shift+Tab を押すとHTMLと同じ字下げでレベルが変わる
- [ ] PowerPointで文字色・サイズ・太字を変更できる（マーカーが画像や焼き込み文字になっていない）
- [ ] 2つ以上選択時のみ「幅をそろえる／高さ／左ぞろえ／上ぞろえ」が出て効く

## 4. 🎨カラーパレット（全スライド一括）
- [ ] 「タイトル文字」を変えると全ページのタイトル色が一括で変わる
- [ ] 「バッジ/ヘッダ背景」「本文文字」「カード背景」「アクセント赤」も一括置換できる
- [ ] ⌘Z でパレット変更が戻る
- [ ] hex欄の値がはっきり読める（a/o・0/O・1/l の区別）

## 5. 📄ページ操作
- [ ] ページの外側（背景）をクリックすると、そのページがオレンジ枠＋「📄このページを選択中」バッジで選択される
- [ ] スクロールしてもバッジが選択ページに追従する
- [ ] テキスト/図形を選ぶとページ選択は自動で解除される
- [ ] 「⧉複製」：選択ページの複製が直後に入る（中身そのまま・番号は振り直し）
- [ ] 「＋追加」：白紙ページが直後に入る
- [ ] 「↑前へ／↓後ろへ」：ページの順番が入れ替わり、番号も振り直る
- [ ] 「🗑削除」：確認の上で削除（最後の1枚は削除不可のアラート）
- [ ] 「背景色」：選択ページだけ背景色が変わる（グラデのページは単色化）
- [ ] パネルに「選択中: N / M ページ目」が出る

## 6. 🖼画像 / ▦表 の挿入
- [ ] 「🖼画像」→クリックで波線枠を置く→⌘V貼り付け or 画像ドロップ or ダブルクリックでファイル選択 で画像が入る
- [ ] 画像をスライドに直接ドラッグ＆ドロップでも入る
- [ ] 「▦表」→クリック位置に表が入る／表を選ぶと行＋行－列＋列－高さ＋高さ－のミニツールバー
- [ ] Excel等からコピーした表を ⌘V で貼ると表になる
- [ ] 表セルの枠線: セルstyleの border / border-top等がPPTXでも同じ辺に線として出る
- [ ] 疑似結合（P18）: 縦3セル同色＋外周線の「大項目」が、PPTX変換後も1つのセルに見える（内側に線が出ない）
- [ ] `<tr style="background:...;color:...">` で書いたヘッダ行がPPTXでも同じ塗り・文字色になる
- [ ] セル範囲選択: 表を選択→セルをドラッグ（またはセルをクリック→端のセルをShift+クリック）で緑枠の範囲選択になる
- [ ] 「大項目」: 範囲選択→ボタンで同色塗り＋外周線になる（内側の線は消える）。「解除」で戻る。⌘Zでも戻る
- [ ] 挿入した画像・表を Delete で消せる（元の本文要素は消えない）

## 7. 📂開く（保存済みデッキの読み込み）
- [ ] 「📂開く」→ HTMLファイルを選ぶ→確認ダイアログ→読み込まれて表示される
- [ ] 読み込んだスライドを移動・編集できる
- [ ] スライドが無いHTMLを選ぶと「見つかりませんでした」と出る
- [ ] 標準の作り（SlideKit製）のデッキは見た目が崩れず開ける

## 8. 📋変更をコピー（Kiro貼付パッチ）
- [ ] 何か動かして📋を押すと「コピーしました（N件）」と出る
- [ ] 貼り付けると `[移動/編集] S3 …data-x Δ+10` の形でテキストが入っている
- [ ] 色変更が `[色置換] 全スライドの #… → #…` で出る
- [ ] 共通要素（タイトル等）を動かすと `[共通] 全ページのタイトル（N枚）…` で1行集約される
- [ ] ページ操作をすると `[ページ構成変更]`（操作履歴＋最終ページ順）が出る
- [ ] 太字・箇条書き・ページ背景の変更もパッチに出る

## 9. 📍参照
- [ ] 要素を選んで📍を押すと、位置ID（S3#5 等）＋outerHTMLがコピーされる

## 9.1 🧩 AI図解相談
- [ ] ページを選択して「案だけコピー」を押すと、そのページ番号・タイトル・HTMLを含むプロンプトがコピーされる
- [ ] オブジェクトだけを選択した場合、そのオブジェクトがあるページを対象にする
- [ ] 何も選択していない場合、画面中央のページを対象にする
- [ ] 「書き換え依頼をコピー」には、SlideKit規約・対象ページだけの置換・レンダリング確認が含まれる
- [ ] コピーされたHTMLに編集UI、選択outline、contenteditable、ページ番号が入らない
- [ ] ボタン操作でスライド本文、編集履歴、保存状態が変化しない
- [ ] ネットワーク通信は発生せず、Kiroへ貼り付けるまで内容が外部へ送られない

## 9.2 ✍️ ラフモード
- [ ] 「✍️ ラフ」を押すと全スライドが手書きフォントになり、各ページ右上に赤い「ラフ」印が出る
- [ ] もう一度押すと元のフォントに戻る（データ・座標は変わらない）
- [ ] ラフ中に💾保存→開き直すとラフ表示が復元される（`<html data-draft="on">`）
- [ ] ラフOFFで保存すると属性ごと消える
- [ ] ラフ中のHTMLをPPTX変換すると警告が出る（出力自体は通常フォント）

## 10. 💾保存
- [ ] 💾を押すとHTMLがダウンロードされる
- [ ] 保存したHTMLを開き直すと、編集UI（ツールバー等）は出るがページ番号は二重にならない（正しい連番）
- [ ] 挿入した画像が保存ファイルにも残っている

## 11. 干渉・後始末
- [ ] 編集OFFにすると選択枠・パレット・ページ操作パネルが消える
- [ ] ツールバーの上でドラッグしてもスライド要素が動かない（誤操作しない）
- [ ] localStorageに保存していない＝リロードすると編集前に戻る（HTML本体が正本）
