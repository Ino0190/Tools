# CalcKit — 表計算＋キット連携

エクセル相当の表計算を単一ページで。`CalcKit/index.html` をダブルクリックで起動
（file://・ビルド不要・外部ライブラリなし）。変更内容はlocalStorageへ自動復旧保存される。
明示的な「保存」は初回だけ保存先を選び、同じセッションでは以後同じ `.calc.json` へ上書きする。
Shift+クリックで別名保存。保存先選択に未対応のブラウザだけDownloadsへfallbackする。

## できること

- **セル編集**: クリック選択→入力、ダブルクリック/F2で編集、矢印/Tab/Enterで移動、
  ドラッグ・Shift+クリックで範囲選択（青枠で囲う）、行/列ヘッダで行列選択
- **フィル**: 選択枠の右下ハンドルをドラッグ（上下左右）。式は相対シフト、
  2セル数値は連番（1,2→3,4…）、「項目1」「4月」は連番、日付は+1日/差分。
  単一の数値はコピー（1セルでは連番か分からないため・Excelと同じ）。
  1セルから連番にしたい時は⌥(Option)を押しながらドラッグ
- **日付型**: `2026-08-14`（/区切りも可）はExcel互換シリアル値として計算できる
  （引き算で日数、`=DATE(y,m,d)` `=TODAY()`、書式ボタン「日付」）。`2026-08` は文字列のまま
- **並べ替え**: 列ヘッダ右クリック→昇順/降順。選択範囲（単一セルなら使用範囲）を対象に、
  先頭行がヘッダなら固定・行内の式は行移動に追従・空セルは常に最後
- **式**: `=B4*40*D4*C4*E4` のようなセル参照・四則・比較・`&`連結・`%`・`$A$1`絶対参照。
  関数: SUM / AVERAGE / MIN / MAX / COUNT / COUNTA / IF / SUMIF / COUNTIF /
  ROUND / ROUNDUP / ROUNDDOWN / ABS / INT / SQRT / VLOOKUP / HLOOKUP / DATE / TODAY
  （evalは使わない自前パーサ。#DIV/0! #REF! #CYCLE! #NAME? #N/A を検出）
- **表引き**: `=VLOOKUP(キー, 範囲, 何列目, [近似])`。第4引数省略はExcel互換の近似一致
  （昇順前提）。**完全一致は `,0` を付ける**（単価表引きは通常こちら）
- **揃え・折り返し**: 左/中/右×上/中/下（同じボタンをもう一度で解除）、
  「折返」で長文をセル内改行（行の高さは中身に合わせて伸びる）。行高は行番号の下端ドラッグでも変更可
- **プルダウン**: セルを選んで「選択肢▾」→1行1候補。セル右の▾クリックで選べる（手入力も可）
- **シート（タブ）**: 画面下部のタブで複数シート。＋で追加、ダブルクリックで名前変更、
  右クリックで複製・削除。**シート間参照**は `=収支!N21` `='シート 2'!A1`（日本語名OK）。
  名前変更すると参照式は自動で追従、シートを削除すると参照は#REF!になる。
  シート越し参照は行挿入・コピペで番地をシフトしない（固定扱い・Excelとの差）
- **Excelと相互コピペ**: ⌘C/⌘VでTSV。CalcKit内コピペは相対参照が自動シフト
- **行/列**: 右クリックで挿入・削除（式の参照は自動で追従、切れたら#REF!）。
  列幅ドラッグ、貼り付け・セル書き込みで足りない分は自動拡張
- **書式**: 太字 / 桁区切り / ¥ / % / 小数2桁。ステータスバーに選択範囲の合計・平均・個数
- **Undo/Redo**: ⌘Z / ⇧⌘Z（80段）

## キット連携（書き出し）

- **スライド書き出し** → SlideKit形式のHTML（data属性表・文字は全部PPTXで編集可能）。
  ダウンロード後そのままブラウザで開けばslide-edit.jsの編集UIも動く。
  Kiroに「PPTXにして」で `SlideKit/html_to_pptx.py` に乗る（run_check・変換・再保存 検証済み）
- **SlideKitからの往復**: デッキ編集中にページ操作の「＋表(CalcKit)」→ CalcKitが別タブで開く
  （前回のシート＝既存の表がそのまま。新規はテンプレートから）→ 範囲を選んで
  ヘッダーの青い「スライドへ追加」→ **表かグラフ（棒/折れ線/曲線/円/ドーナツ）を選んで**
  デッキの現在ページ直後に1枚入る。表はPPTXネイティブ（編集可能）、グラフはDKのSVGを
  焼き込んだ画像（タイトル・凡例の文字は編集可能）。
  使い分け: 静的な小さい表はSlideKit上で直接（Excelドロップ/⌘V）、計算する表はCalcKitで
- **ガント書き出し** → 列マッピング（項目名/開始/終了/グループ等）を指定して
  **「GanttKitで開く」**（別タブでそのままガント表示）か「データjsを保存」（ファイル化）。
  日付は YYYY-MM / YYYY-MM-DD（/区切りも可）
- **GanttKitから表として開く**（逆方向）: GanttKitヘッダーの「表(CalcKit)で開く」で
  グループ/項目/段階/開始/終了/日数（式）/説明の表になる。マイルストーンは別シート。
  表⇄ガントを行き来できる（表で一気に入力→ガントでドラッグ調整→表に戻して集計）
- **グラフ** → DashboardKit（`../DashboardKit/dashboard-kit.js` 読込時のみ）で
  棒/折れ線/曲線/円/ドーナツをプレビュー。範囲の短い方の次元を系列に自動判定
- **CSV / Excel(.xls)**: 値で書き出し。CSV/TSVの読み込みも「開く」から
- **Excel(.xlsx)・式ごと納品用**: `python3 CalcKit/calc_to_xlsx.py 対象.calc.json [出力.xlsx]`。
  式（SUM/IF/VLOOKUP・シート間参照）が生きた式のままExcel化され、¥/%/日付書式・bold・
  揃え・折り返し・プルダウン・列幅/行高も反映。顧客にExcelで渡す時はこちら。
  検証は `--selftest`（式保持・シート間参照・書式の読み戻し確認）

範囲指定の書き出しは「複数セルを選択して押す」。単一セルのままなら使用範囲全体。

## Kiroに頼むとき

`.calc.json`（保存ファイル）を渡して「この表を◯◯にして」でよい。
構造: `{name, active, sheets:[{name, rows, cols, colW, rowH, cells:{"A1":{v:"値 or =式", fmt, bold, align, valign, wrap, opts}}}]}`
（align: l/c/r、valign: t/m/b、wrap: 1=折り返し、opts: プルダウン候補の配列。
旧形式の単一シートJSONも読み込み時に自動移行）。
ブラウザ側APIは `window.CalcKit`（setCell/val/display/select/buildSlideHtml/
buildGanttData/buildChartData/loadTemplate 等・check.py参照）。

## 検証

```
python3 CalcKit/check.py
# main=式・VLOOKUP・フィル・日付・ソート・揃え/折返/プルダウン・書き出し30項目
# ＋SlideKit往復E2E ＋実運用シナリオ（単価改定・返済感度・性能・PPTX変換パイプライン全通し）
```
